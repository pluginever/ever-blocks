Ever Blocks is a professional page building blocks for the WordPress Gutenberg block editor.

== Description ==
Ever Blocks is a versatile WordPress plugin designed to enhance your website by adding beautifully formatted alert boxes along with additional customizable content blocks. This plugin is perfect for drawing attention to important information, showcasing team members, displaying testimonials, and presenting content in card formats.

== Installation: ==
###Automatic Installation From WordPress Dashboard

1. Login to your admin panel
2. Navigate to Plugins -> Add New
3. Search **Ever Blocks**
4. Click install and activate respectively.

###Manual Installation From WordPress Dashboard

If your server is not connected to the Internet, then you can use this method-

1. Download the plugin by clicking on the red button above. A ZIP file will be downloaded.
2. Login to your siteâ€™s admin panel and navigate to Plugins -> Add New -> Upload.
3. Click choose file, select the plugin file and click install

###Install Using FTP

If you are unable to use any of the methods due to internet connectivity and file permission issues, then you can use this method-

1. Download the plugin by clicking on the red button above.A ZIP file will be downloaded.
2. Unzip the file.
3. Launch your favorite FTP client. Such as FileZilla, FireFTP, CyberDuck etc. If you are a more advanced user, then you can use SSH too.
4. Upload the folder to wp-content/plugins/
5. Log in to your WordPress dashboard.
6. Navigate to Plugins -> Installed
7. Activate the plugin


== Frequently Asked Questions ==
= How do I add an alert box to my post/page? =
- In the WordPress editor, click on the Ever Blocks icon.
- Select your preferred alert style from the dropdown menu.
- Customize the alert content as needed.
- Insert the alert box into your post or page.

= Can I customize the look of the alert boxes? =
Yes, you can customize the content and style of each alert box. The plugin provides options to adjust colors, icons, and text to match your website's design.

= Is Ever Blocks compatible with all themes? =
Ever Blocks is designed to work with most WordPress themes. However, if you encounter any compatibility issues, please contact our support team for assistance.
